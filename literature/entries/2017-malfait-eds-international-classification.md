# Summary

- International consensus reclassification of the Ehlers-Danlos syndromes into multiple clinically defined types with major/minor criteria and genetic correlates where known.
- Separates hypermobile EDS (hEDS) from other rarer EDS types and from non-EDS hypermobility presentations.
- Provides explicit criteria sets intended to reduce both under- and over-diagnosis of EDS.
- Works in tandem with the hypermobility spectrum disorder (HSD) framework for symptomatic hypermobility that does not meet hEDS/other EDS criteria.

# Key data points

- EDS is a group of heritable connective-tissue disorders, not a single disease.
- hEDS remains a clinical diagnosis (no single highly sensitive gene test for most patients).
- Meeting or failing hEDS criteria changes the label but does not erase symptomatic joint instability if HSD features remain.
- Vascular and other rare EDS types have distinct red-flag criteria—important not to conflate with generalized arthralgia.

# Caveats

- Classification paper, not a treatment trial.
- “EDS cleared” should be interpreted with attention to which criteria set and which clinician applied them.
- Genetic testing panels vary; negative panel ≠ no connective-tissue contribution.
- Not medical advice; educational research note only.
