# Why this card exists

H3 — the working model in which calcium loss through the urine drives the bone loss —
carried an **empty contradicting-literature list**. That emptiness was honest about the
filing but easy to misread as "nothing argues against this." This card is one of three
filed in v0.4.0 to close that gap.

# What it addresses

Whether urinary calcium excretion, on its own, tracks bone density closely enough to
account for a reading this low. That is the step H3 depends on, and it is the step with
the least support behind it.

# Scope limits (read before citing)

- **Used at abstract level only.** No numeric result from this paper is carried into any claim,
  hypothesis or public page. It is cited for its question, not for its figures. The full text is
  open in PMC (PMC5514609) — this is a limit on how the card is used, not on what is available.
- Cohort is calcium stone formers, which overlaps this record only partially — the
  documented stone history is a single episode (see lit-0339's note on the same issue).
- Citing this card does **not** state that H3 is wrong. It states that H3 has a named
  counter-consideration on the record, which is a different and weaker claim.
