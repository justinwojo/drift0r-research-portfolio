# Code of Conduct

> **Research only — not medical advice.** This project is a tightly gated research evidence portfolio, not a clinical service or unmoderated forum.

## Our standards

We aim for a constructive, evidence-oriented community around corrections, literature, and research framing.

**Expected behavior**

- Be respectful and assume good faith when challenging claims or methods.  
- Prefer citations (DOI, PMID, PMCID, official guideline URLs) over assertion.  
- Keep discussion on public research materials — not personal medical advice.  
- Protect privacy: never post private medical records or third-party identifiers.  
- Accept that maintainers may re-label, request sources, decline, or close issues.

**Unacceptable behavior**

- Harassment, threats, or personal attacks  
- Posting private medical records, lab PDFs, imaging, or clinic notes in public issues  
- Doxxing or sharing non-public personal information  
- Spam, brigading, or bad-faith flood of low-signal issues  
- Presenting unsupported diagnoses as clinical fact or demanding treatment instructions  
- Using this project to promote unlicensed clinical practice or commercial medical scams

## Scope

This Code applies to project spaces: GitHub issues, pull requests, discussions (if ever enabled), and other official project channels. It also applies when an individual is representing the project in public spaces in that capacity.

## Enforcement

Maintainers may:

1. Edit, hide, or delete content that violates this Code or project contribution rules.  
2. Close issues/PRs and lock threads.  
3. Temporarily or permanently restrict participation.  
4. Report illegal content to platform operators or authorities when appropriate.

Public GitHub issues and comments are **public** and may remain visible, cached, or forked after moderation. Do not treat a public issue as a private channel.

## Reporting

There is **no published project email address** for conduct reports.

| Situation | Channel |
|-----------|---------|
| Code of conduct concern about public project spaces | GitHub issue using the **Correction, privacy, or removal request** template, or contact GitHub Support if the matter involves platform abuse |
| Privacy / removal of published portfolio content | Same correction/privacy issue template — **do not attach private records** |
| Security vulnerability | See [SECURITY.md](SECURITY.md) |
| Sensitive Drift0r consent / withdrawal | Existing private correspondence with the repository owner |
