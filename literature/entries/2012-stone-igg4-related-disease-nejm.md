# Summary

- Landmark NEJM review that established IgG4-related disease (IgG4-RD) as a multi-organ fibroinflammatory concept (tumefactive lesions, IgG4-rich infiltrates, storiform fibrosis, variable serum IgG4).
- **Source-access limit:** NEJM full text is paywalled; PubMed publishes **no abstract** for this review; no local PDF is held. The bullets below are **unverified against source text** and must not be treated as quote-level support.
- Public use on this site is limited to: serum IgG4 elevation is not itself diagnosis of classic fibrotic multi-organ IgG4-RD; classification requires clinicopathologic correlation (use lit-0096 / lit-0097 for formal criteria language).

# Key data points (unverified against full text — bibliographic framing)

- Review-class source defining the modern IgG4-RD clinicopathologic concept (2012).
- Serum IgG4 elevation alone is not diagnostic of fibrotic multi-organ disease.
- Pre-dates 2019 ACR/EULAR classification and 2020 RCD criteria (prefer those for classification thresholds).
