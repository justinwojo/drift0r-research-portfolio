# Information request from the BIPU case review

This is a respectful request for additional context, not a request to take over this project.

The Build in Public University review of the publicly available case materials found the portfolio's evidence structure useful and its limitations unusually candid. We opened a small set of bounded research questions in a companion fork so that possible new information can be tracked without crowding this repository's existing discussion:

- [Companion repository](https://github.com/leo-guinan/drift0r-research-portfolio)
- [DXA records and facility LSC](https://github.com/leo-guinan/drift0r-research-portfolio/issues/2)
- [Bone turnover phenotype](https://github.com/leo-guinan/drift0r-research-portfolio/issues/3)
- [Early-onset low BMD / genetic-workup review](https://github.com/leo-guinan/drift0r-research-portfolio/issues/4)
- [Humoral immunity / specific antibody deficiency](https://github.com/leo-guinan/drift0r-research-portfolio/issues/5)
- [Small-fiber/autonomic assessment](https://github.com/leo-guinan/drift0r-research-portfolio/issues/6)

The highest-value information would be primary-record context that could falsify or narrow the current models: original DXA printouts and facility precision data; assay metadata for specialty infectious testing; original tryptase/TPSAB1/KIT reports; vaccine history and same-laboratory antibody response data; and clarification of the provenance and intended meaning of the IgG4-related-disease wording.

No private records are requested in this PR. Please do not attach medical documents, identifiers, or private correspondence to a public GitHub thread. If maintainers or the patient choose to answer, a short public-safe correction, pointer, or statement that a question is not answerable would be useful. No response is expected, and no diagnosis is implied.

This document is a proposed communication surface. It does not alter the site's medical content, assert clinician review, or require acceptance. Maintainers may edit, reject, or close it.
