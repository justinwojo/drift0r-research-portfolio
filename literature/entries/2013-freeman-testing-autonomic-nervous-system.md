# Summary

- Methods-oriented review of clinical autonomic testing: most of the ANS is inaccessible to direct testing, so end-organ responses to standardized provocations are used.
- Cardiovascular parasympathetic function via heart-rate variability maneuvers; sympathetic function via blood-pressure responses to physiological stimuli.
- Tilt-table testing for neurally mediated syncope, postural tachycardia syndrome (POTS), and orthostatic hypotension.
- Sudomotor assessment: QSART / QDIRT for distal postganglionic cholinergic fibers; thermoregulatory sweat test for global pre- and postganglionic sudomotor map.
- Notes frequency-domain HR/BP variability, microneurography, and baroreflex tools as primarily research-level.

# Key data points

- Clinical ANS workup is modular: cardiovagal + adrenergic + sudomotor domains, often summarized with composite scores (e.g., CASS in Mayo-style labs).
- QSART specifically tests postganglionic sympathetic cholinergic sudomotor axons—relevant to small-fiber autonomic neuropathy.
- Tilt testing distinguishes orthostatic hypotension vs POTS vs vasovagal predisposition.
- No single test equals “dysautonomia”; pattern across domains matters.

# Caveats

- Chapter, not a diagnostic criteria paper for a specific disease.
- Medications (including anticholinergics, some antidepressants, antihypertensives) confound autonomic tests.
- Research catalog only.
